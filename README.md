# AI Credit Transfer — Hackathon Project

**Academic Hackathon Project | 2026**

## Project Overview

AI Credit Transfer is a hackathon project concept focused on improving the university course credit transfer process.

The project explored how an AI-assisted workflow could help reduce repetitive document checking, duplicate data entry, and manual course comparisons.

## My Role — System Analysis

I was responsible for system analysis as part of the hackathon team.

My contributions included:

- Analyzed problems in the existing manual credit transfer process.
- Identified repetitive tasks, including document verification and duplicate data entry.
- Studied the workflow for comparing courses and supporting documents.
- Helped identify user needs and opportunities for process improvement.
- Collaborated with teammates to propose a more efficient system workflow.

## Proposed Solution

The team explored an AI-assisted credit transfer workflow involving:

- Digital submission of credit transfer documents
- Extraction of relevant document information
- Assistance with course information comparison
- Improved review and approval workflows

OCR, NLP, and AI-assisted processing were considered as part of the proposed approach, not claimed here as fully implemented features.

## Project Workflow

1. Analyze the existing credit transfer process.
2. Identify problems and user needs.
3. Define opportunities for improving the workflow.
4. Design a proposed AI-assisted solution.
5. Present the concept as part of the hackathon.
